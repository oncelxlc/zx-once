# 开发者工作台

浏览器和 Tauri 主窗口共用一套哈希路由。Windows 原生标题栏在应用名称右侧依次提供「返回」「前进」和主导航开关，浏览器版在底部状态栏提供相同操作。主导航首次显示为 52px 图标栏，悬停或用键盘聚焦可查看名称。点「展开导航」显示 224px 侧栏，切页和重开工作台时保留选择。窄窗使用该按钮打开导航抽屉。[路由入口](../../src/App.tsx) · [导航操作](../../src/app/WindowNavigation.tsx) · [主导航](../../src/app/AppSidebar.tsx)

页头和正文位于同一块圆角主内容区，页面标题与主要操作固定在顶部。有多个视图的模块使用独立的文字导航，通过底色和字重标出当前项。选择子页面后可刷新当前地址，也可用前进或后退返回之前的视图。长页面在内容区内滚动，两级导航可分别滚动。小于 800px 的窗口中，二级导航横向排列。资源详情在宽窗口停靠于右侧，空间较小时显示为抽屉。[共享页面布局](../../src/app/WorkbenchPage.tsx)

返回和前进按当前窗口访问过的页面、子页面及资源上下文移动，例如 Git 仓库、GitHub 账户和远程主机。重复打开同一视图、修改筛选、编辑草稿或开合弹窗不会增加一站。返回后打开新页面会清除原有前进分支。没有对应历史记录时，箭头变淡并禁用。主导航展开期间，开关保留选中底色。悬停可查看按钮名称。刷新会从当前哈希地址开始一段新历史。[导航历史](../../src/app/navigationHistory.ts)

`Alt+←` 和 `Alt+→` 可执行返回和前进。焦点在文本输入、下拉选择和终端输入区时，这两个快捷键不会切换页面。`Ctrl+B` 可切换一级导航。[路由与快捷键](../../src/app/useWorkbenchNavigation.ts)

Windows 原生标题栏的空白区域可拖动或双击，系统菜单和右侧窗口按钮由 Windows 处理。进入全屏时标题栏和导航按钮一同隐藏。关闭主窗口后可从托盘重开。底部状态栏显示应用版本和已连接的演示主机数。未知路由回到总览。[主窗口配置](../../src-tauri/tauri.conf.json) · [工作台外壳](../../src/app/AppShell.tsx)

## 页面与操作

| 页面 | 哈希路由 | 可以做什么 |
| --- | --- | --- |
| 总览 | `#/` | 从最近项目、开发环境、Git 动态、GitHub 待办、远程连接和活动记录进入对应资源。「自定义总览」可调整卡片顺序及显隐。卡片在各列中从上到下紧邻排列，窄窗口显示为单列。 |
| 灵动岛 | `#/island` | 从主导航的「工作台」分组打开灵动岛设置，调整草稿并预览外观。Windows 桌面支持保存配置和控制岛体。[灵动岛操作](island.md) |
| 项目 | `#/projects` | 搜索项目，按语言或标签筛选，切换列表与网格。可新增、编辑、移除演示项目，复制路径或固定到首页。详情可跳到关联的环境、仓库和主机。 |
| 开发环境 | `#/environment` | 按运行时、工具链或包管理器查看资源。可筛选安装状态、查看安装说明、模拟检测，并在已有版本间切换默认值。 |
| Git 工作区 | `#/git` | 选择样本仓库及分支，查看文件变更、提交记录、分支和远端。可模拟克隆、修改文件、提交、拉取和推送。提交会更新该分支的记录及领先数量。 |
| GitHub | `#/github` | 切换演示账户，搜索仓库、PR 和 Issue，查看协作活动。仓库详情可进入已有的演示 Git 工作区，或打开模拟克隆入口。 |
| 远程中心 | `#/remote` | 按主机切换 SSH 连接、服务器指标、文件、终端、Docker 资源和部署日志。模拟连接后，可将样本文件加入传输队列，或在终端会话中输入命令查看预设回显。 |
| 工具箱 | `#/toolbox` | 在「全部工具」内搜索，或从二级导航直接打开 JSON 格式化、UTF-8 Base64 编解码、时间戳转换。时间戳支持秒、毫秒、UTC 和本地时区。可复制结果或清空输入。 |
| 设置 | `#/settings` | 默认显示「外观」，可选择浅色、深色或跟随系统，也可直接访问 `#/settings/appearance`。「导航自定义」对应 `#/settings/navigation`，可管理分组、顺序、显隐和收藏。 |

主导航的「最近使用」和「活动记录」分别定位到总览中的对应模块，地址为 `#/?section=recent` 和 `#/?section=activity`。总览和项目列表直接使用整个内容区。隐藏主导航入口后，仍可按原地址访问。[导航定义](../../src/app/navigation.ts)

## 数据与保存范围

| 数据 | 存放位置与生命周期 |
| --- | --- |
| 项目、环境、Git、GitHub、远程资源和活动记录 | 各模块的 Redux 状态从内置样本初始化，当前窗口的页面共享。比如在项目详情选择「固定到首页」，总览的最近项目会显示同一条记录。刷新页面或重建主窗口后重新加载样本。模拟操作只更新演示记录。 |
| 主题、侧栏和导航分组 | 保存在当前浏览器或 WebView 的 `localStorage`，键名为 `zx-once.workbench.preferences.v1`。 |
| 总览布局、最近使用的工具 | 分别保存到 `localStorage` 的 `zx-once.overview.layout.v1` 和 `zx-once.toolbox.recent.v1`。工具记录只含工具标识。输入和转换结果仅在当前工具视图中保留。 |
| 主窗口会话 | 在灵动岛设置页关闭 Windows 主窗口后，托盘的「打开主界面」可恢复该页的有效分组与草稿。从其他业务页面关闭主窗口后重开会进入总览。退出应用会释放这份内存快照。 |

在总览或业务样本页打开「演示数据」菜单，可切换加载中、无数据或读取失败，GitHub 和远程中心还可切换无权限。项目路径复制和工具箱结果复制使用设备剪贴板。[状态入口](../../src/store.ts) · [演示状态控件](../../src/app/workbenchUi.tsx) · [工具转换](../../src/features/toolbox/conversions.ts) · [窗口快照](../../src-tauri/src/island/manager/main_window.rs)
