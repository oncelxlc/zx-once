# 待操作验证清单

后续尚未验证的操作及预期结果统一记录在此，待用户确认后集中验证。[操作验证约定](../../AGENTS.md#操作验证)

无界面 Chrome 已在 1280 × 720 浅色、1440 × 560 深色和 390 × 640 深色窗口检查 11 个页面入口。33 组检查均确认页面根容器与视口等大、状态栏位于底部；有长内容时，滚动正文不会移动页头或导航。桌面尺寸下也已核对顶栏、一级导航和状态栏的实际背景色一致。

- [ ] 在 Windows 桌面查看总览的六张默认卡片，确认按列连续排列。在「设置 → 外观」选择「跟随系统」，切换 Windows 明暗外观，确认顶栏、主导航和状态栏在两种主题中均同色，文字、选中项和边界清晰。
- [ ] 在 Windows WebView 中悬停及用键盘聚焦收起的图标，检查提示位置、组间短线居中和底部设置入口。用顶栏按钮在展开或收起动画中途反向切换，检查分组标题和图标过渡。
- [ ] 在低高度窗口分别用滚轮滚动两级导航，检查设置入口和当前分组的可见性。窄屏浏览器中用触控打开主导航抽屉、横向浏览二级导航，并到达长表单的底部。
- [ ] 在 Windows 标题栏空白处拖动窗口，依次验证最小化、最大化、还原和关闭。关闭后从托盘重新打开，确认主窗口控件仍可操作。
- [ ] 分别在主窗口打开和已关闭至托盘时，点击 Windows 托盘菜单「灵动岛设置」，确认两种情况下都能打开灵动岛设置页。
- [ ] 在灵动岛「动画效果」分组修改一项设置，保留未保存的草稿并关闭主窗口。从托盘点击「打开主界面」，确认恢复该分组和草稿。
